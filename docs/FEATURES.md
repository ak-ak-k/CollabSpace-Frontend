# Feature status

CollabSpace is a **frontend prototype**. Every screen below runs in the browser on built-in demo data; there is no backend, no real authentication and no persistence yet. This matrix exists so that descriptions of the project never claim more than the code supports.

**Frontend status**

| Status       | Meaning                                                                              |
| ------------ | ------------------------------------------------------------------------------------ |
| Implemented  | The UI and its client-side behaviour are complete for the current scope.             |
| Partial      | Usable, but some behaviour is simulated or missing. Details are in the Notes column. |
| UI prototype | The screens work, but the underlying behaviour is simulated.                         |
| Planned      | Not built yet.                                                                       |

**Integration status** says where the data comes from.

Last verified: 22 October 2026, against commit `355e2f1`. Evidence comes from scripted browser runs on a local production build and on the deployed site, plus the unit test suite (166 spec files, 600 tests).
